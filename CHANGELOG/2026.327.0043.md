# 2026.327.0043 — fix(immich): drop the stale inline description from the immich skill node

## Summary

The `immich-skill` routing node still carried an inline `description:` — the ML-enabled
text added in #19 — while the `SKILL.md` frontmatter kept its own wording. The marketplace
generator refuses a node whose inline body disagrees with its file:

```console

```

#19 updated the inline copy in the node but not the file frontmatter, so the two drifted.
This deletes the node's inline copy: the node is routing only (`name`/`family`/`owner`), and
the file frontmatter is the body, per the skill contract.
