# 2026.326.1824 — feat(immich): build Immich v3.4.2 and describe the single ML image

## Summary

Bumps Immich from **v3.4.1** to the latest stable **v3.4.2** (2026-11-18). The release
is a bugfix patch: pnpm 12.15.0, Node 24.22.1, uv 0.8.15, Python 3.13 and the Natural
Earth tag v5.1.2 are unchanged, so only the two version literals (`IMMICH_SOURCE_REF`
and `IMMICH_VERSION`) and the prose that names the release move. The source tarball,
plugin-core, server, web UI and the ML virtualenv all derive from `IMMICH_VERSION`.

The same change corrects the documentation to the shape the candy already has: ONE
image with the in-process ML backend on port 3003 (no CPU-only variant, no separate
`immich-ml` image), the box is `immich-cdi` on the `podcdi.pod-cdi` base, and the
database host is the unix socket directory. The stale `immich-skill` description that
still said “CPU-only (no ML)” is fixed.
